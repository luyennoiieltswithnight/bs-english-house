Xem trước & Xuất bản

🚀 Xuất lên web (GitHub Pages)

Công cụ gọi thẳng GitHub API từ trình duyệt của bạn để tạo/cập nhật file — không qua máy chủ nào khác. Token chỉ lưu trong trình duyệt này (localStorage), không gửi đi đâu ngoài api.github.com.

Personal Access Token (PAT) là gì? Đây là một "mật khẩu riêng" GitHub cấp để cho phép công cụ này ghi file vào đúng 1 repo của bạn, thay vì dùng mật khẩu GitHub thật (an toàn hơn, có thể thu hồi bất cứ lúc nào).
Vì sao không điền sẵn token vào code luôn? Vì trang này (và mọi file trên GitHub Pages) là công khai — ai xem "View Source" cũng đọc được. Nếu gắn token thẳng vào code, bất kỳ ai cũng có thể lấy trộm token đó và ghi/xoá bất cứ gì trong repo của bạn. Token chỉ nên nằm trong trình duyệt của riêng bạn.
Tin vui: chỉ cần nhập một lần duy nhất — tick ô "Lưu lại" bên dưới (mặc định đã tick sẵn), lần sau mở tool lên là tự điền, không phải gõ lại.
Chọn quyền "repo" (hoặc với Fine-grained token: "Contents: Read and write" cho đúng repo bs-english-house) rồi copy token dán vào ô dưới.
